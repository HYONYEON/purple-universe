키 발급 방법
1. github.com 로그인 → 오른쪽 위 프로필 → Settings
2. 맨 아래 Developer settings → Personal access tokens → Tokens (classic)
3. Generate new token (classic) 클릭
4. Note에 아무 이름, Expiration은 90 days 권장 (만료되면 다시 발급)
5. 체크박스 중 repo 하나만 체크
6. 아래 초록 버튼 → 생성된 ghp_로 시작하는 문자열을 복사

이 키는 마파님 브라우저에만 저장되고, 사이트에는 올라가지 않아요.
